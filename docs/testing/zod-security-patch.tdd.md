## Minimal fix

- Raise direct/shared Zod floors from `^4.4.3` to `^4.6.6`; all four active workspace lockfiles
  resolve the official patched **4.6.7** release. No other dependency version is changed.
- Bump private contracts metadata from 0.2.0 to 0.2.1 so npm refreshes the local package metadata.
  Its JavaScript exports, TypeScript declarations and all application source/config remain identical.
- Updating only Zod or running `npm update @haircut/contracts` left stale local-package metadata.
  Explicitly reinstalling the existing file dependency refreshed it; lockfiles were generated by npm.
- Retain all ordinary input/output behavior; do not introduce new business limits or repair APIs.

Primary evidence: [advisory](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5),
[upstream size-gate fix](https://github.com/colinhacks/zod/commit/a0ebf97),
[patched release](https://github.com/colinhacks/zod/releases/tag/v4.6.7).
This fixes leading collection size checks, not every possible resource-exhaustion vector.
Schemas without an appropriate size bound are not made bounded by this update.

## Setup corrections and warnings (not hidden application failures)

- The first combined Web command incorrectly applied `VITE_APP_ENV=production` to unit tests:
  2 fixture-guard tests failed / 299 passed. Running tests with `VITE_APP_ENV=test`, then building
  separately in production mode, passed all 301. No production guard or application test was weakened.
- Initial Java 21 emulator startup failed to create a Windows Unix-domain socket. A task-specific,
  short `jdk.net.unixdomain.tmpdir` fixed it per process; no system/firewall settings were changed.
- Initial integration used `demo-haircut-zod-security`: 164 passed / 1 photo fixture failed because
  that fixture expects the `demo-haircut.appspot.com` bucket. The existing bucket-isolation guard
  correctly excluded it. Running the CI-equivalent `demo-haircut` project passed all 165, unchanged.
- A version-inspection command tried to require a non-exported contracts package.json. The seven
  Manager guards had passed; inspection was corrected to read metadata beside the resolved entry.
- Rollup warns about two upstream CJS pure annotations and removes those comments. Builds succeed;
  no vendor patch or warning suppression was added. Existing Manager tooling/chunk warnings remain.
- The Rules emulator prints the Java options notice and a denial-case missing-field evaluation
  message; the complete 35-test result is PASS. An approval-review timeout prevented one launch;
  the allowed single retry ran successfully. This was not counted as a Rules test execution.
